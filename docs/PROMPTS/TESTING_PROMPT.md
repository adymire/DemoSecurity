# Testing Prompt

Create a complete test matrix for:

- authentication
- onboarding
- installation registration
- device correlation
- IP/network changes
- account reuse
- disposable email signals
- request velocity
- rate limits
- risk scoring
- policy decisions
- restrictions
- admin authorization
- audit logs
- SDK event spoofing
- replay attacks

Explicitly test legitimate shared networks and changing IPs so the system does not create simplistic false positives.
